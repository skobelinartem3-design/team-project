# Лабораторная работа №6 — Team Game Arcade

Текстовая пошаговая игра на рекорд по мотивам Fallout: герой собирает крышки, рискует в рейдах и участвует в рулетке Пустоши.

## Индивидуальное выполнение

Работа выполняется одним автором — [skobelinartem3-design](https://github.com/skobelinartem3-design). Репозиторий фиксирует реальные Issues, ветки, Pull Requests и squash-слияния, но не заявляет о проверке коллегами: одобрение собственного Pull Request GitHub не допускает.

## Сборка

```sh
g++ -std=c++17 -Wall -Wextra -Wpedantic lab6-team-game-arcade/game.cpp -o game
./game
```

## Задачи

- Issue #1: рискованный рейд;
- Issue #2: лечение и экономика крышек;
- Issue #3: рулетка D20.

Каждая функциональная задача выполняется в отдельной ветке и вливается через Pull Request с ключевым словом `Closes #ID`.
